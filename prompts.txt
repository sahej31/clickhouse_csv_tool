Prompt 1:
Build a Flask web application that allows users to connect to a ClickHouse database using JWT tokens and export data from selected tables to CSV. Include UI for user inputs and Flask backend to handle ClickHouse connection and CSV export.

Prompt 2:
Add functionality to the same Flask app to also import data from a user-uploaded CSV file into a new ClickHouse table. Let users specify the table name, selected columns, and connection parameters. Handle both flows (ClickHouse → CSV and CSV → ClickHouse) with streaming/batch support.

Prompt 3:
In the front-end HTML/JavaScript, create dynamic forms that update based on the selected mode (ClickHouse to CSV or CSV to ClickHouse). Use the Fetch API to connect with Flask endpoints for each action.

Prompt 4:
Write a Dockerfile and docker-compose.yml to containerize the application. Ensure the app runs on port 5000 and installs dependencies from `requirements.txt`.

Prompt 5:
Build a unified JavaScript logic that toggles UI components based on user input, fetches ClickHouse table/column data via AJAX, and shows status/result messages after ingestion.

Prompt 6:
Design the CSS to provide clear form styling, with selection boxes for columns/tables and visually distinct status messages.

Prompt 7:
Ensure the ingestion process supports multi-table joins when exporting from ClickHouse to CSV. Add input for user-defined JOIN conditions and use aliases like `t1`, `t2` in SQL queries for safe JOINs.
